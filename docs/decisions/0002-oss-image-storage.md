# 0002: 图片存储使用阿里云 OSS，本地存储兜底

- 状态：已接受
- 日期：2026-07
- 取代：无

## 背景

用户图片持续增长，纯本机磁盘面临容量、备份、出网带宽压力；开源版则需要不依赖云厂商即可自部署。

## 决策

**我决定**：SaaS 生产默认使用阿里云 OSS；后端保留 `Storage` 抽象与本地实现，由 `OSSConfigured()` 决定走 OSS 还是本地磁盘。

## 备选方案

- 纯本地磁盘：否决——单机容量/带宽/备份压力，扩容需停机。
- 其他对象存储：否决——迁移与配置成本，现有资源已适配阿里云。

## 后果

### 正面

- 卸载磁盘与出网带宽，天然多副本；本地实现保证开源版可自部署。

### 负面 / 代价

- 引入外部依赖与费用。
- 存量图片迁移成本；小程序 `pages/Guide` 教程图硬编码 `OSS_PUBLIC_URL`，换存储需同步改前端。
