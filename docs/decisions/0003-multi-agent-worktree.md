# 0003: 多 Agent 使用 git worktree + deploy.sh 隔离

- 状态：已接受
- 日期：2026-07
- 取代：无

## 背景

多个 Agent 在同一台服务器上开发同一仓库，直接共享工作目录会互相覆盖未提交修改，部署也可能把半成品带上线。

## 决策

**我决定**：每个 Agent 用 `git worktree` 在独立目录、独立分支（`feat/*`）开发；部署统一走 `deploy/deploy.sh --branch <feat>`，脚本加 `flock` 互斥、健康检查通过后才把分支合入 `main`。

## 备选方案

- 共享目录直接改 `main`：否决——互相覆盖、部署污染。
- 各自独立 CI/CD：否决——资源与维护成本高。

## 后果

### 正面

- 开发互不阻塞、可回滚；部署串行且带健康门禁。

### 负面 / 代价

- 部署脚本复杂（快照/回滚/迁移），改动风险集中在脚本本身。
- 分支需及时合并，否则滞后。
