# 0006: 删除 sys_configs，配置全部来自环境变量

- 状态：已接受
- 日期：2026-09
- 取代：无

## 背景

配置中心化（`sys_configs` 表）带来额外 DB 依赖、缓存失效与 `deploy.sh` 回写逻辑；但配置项极少变更，中心化收益为零。

## 决策

**我决定**：删除 `sys_configs` 表（迁移 `000006_drop_sys_configs`）与 `default_diary_config`；配置全部来自环境变量或代码默认值（`config.go` 为纯环境变量）。000003 种子迁移中的 `sys_configs` 行仅为历史产物，由 000006 删除。

## 备选方案

- 保留表 + 管理界面做热更新：否决——过度设计，运维成本高于收益。

## 后果

### 正面

- 少一张表、少一条配置链路；部署即配置，来源唯一。

### 负面 / 代价

- 变更配置需重新部署/重启进程（配置低频变更，可接受）。
