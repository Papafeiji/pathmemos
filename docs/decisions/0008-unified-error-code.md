# 0008: 错误响应词汇统一（code 固定枚举 + biz_code 语义码）

- 状态：已接受
- 日期：2026-09
- 取代：无

## 背景

历史上部分语义串（`RATE_LIMITED`/`SESSION_INVALID`/`TEXT_TOO_LONG`…）被直接放在 `code`；同一 `biz_code` 在不同端点返回不同 HTTP 状态（如 `NOT_VIP` 403/400 并存）。前端错误处理分支混乱，契约无法全量回归。

## 决策

**我决定**：`code` 固定枚举 `0000/4000/4010/4030/4040/4090/4130/4290/5001`；语义标识符一律放 `biz_code`；同一 `biz_code` 全端点同一 HTTP 状态（`errors.HTTPStatus` 唯一映射）；SSE error 事件体与上传超时包同步收敛。词汇表见 `spec/03-api.md` §3。

## 备选方案

- 维持现状并仅文档化：否决——语义码/数字码混用会随端点增长继续恶化。

## 后果

### 正面

- 前端单一分支逻辑（HTTP 状态 + biz_code 两个维度即完备）。
- 契约可按词汇表逐行回归。

### 负面 / 代价

- 一次 breaking 变更，需前后端同发。
