# 0009: 开源版内置加密微信 AppID/Secret

- 状态：已接受
- 日期：2026-09
- 取代：无

## 背景

开源版要求开箱即用；默认微信小程序凭证若以明文存在于源码，会被自动化扫描直接抓取滥用。

## 决策

**我决定**：以 AES-GCM 加密内置开源版默认的微信小程序 AppID/Secret（密钥由固定盐经 SHA-256 派生），属**轻量混淆**而非保密机制；用户可用自己的 `WECHAT_APPID`/`WECHAT_SECRET` 覆盖。仅 open 模式回退使用内置值。

## 备选方案

- 明文内置：否决——会被爬虫直接抓取。
- 不内置、强制用户配置：否决——开箱即用体验不可接受。

## 后果

### 正面

- 开箱即用；避免明文被机器人直接抓取。

### 负面 / 代价

- 有心人可逆向还原；该共享凭证存在被滥用消耗配额的风险，接受。
