# 0010: 家庭邀请链接长期有效且无撤销

- 状态：已接受
- 日期：2026-09
- 取代：无

## 背景

家庭邀请链接 `linkId = familyId`，任何登录用户持有即可加入（owner 携整家合并）；链接无过期、无撤销、无邀请人确认。

## 决策

**我决定**：维持现状（长期有效、无撤销）。理由：家庭规模 ≤6 人；链接经微信私聊/分享小范围传播；误加入可由 owner 随时移除；引入邀请令牌表/过期/撤销的复杂度与收益不匹配。

## 备选方案

- 独立邀请令牌 + 过期 + 撤销：否决——当前规模下收益不成比例，留待出现真实滥用再立项。

## 后果

### 正面

- 零额外表与流程，分享体验最简。

### 负面 / 代价

- 链接外泄可致陌生人加入。缓解：成员上限 6、owner 可移除成员、合并行为可预期。
